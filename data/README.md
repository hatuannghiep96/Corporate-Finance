# data/

Stores all source financial data used as 
inputs for models and analysis in BUS-629.

## What belongs here
- Downloaded financial statements (PDF or Excel)
- Exchange rate and macro data
- Any third-party dataset used as model inputs

## Provenance requirement
Every data file must have a companion note 
documenting:
- Source: where the data came from (URL or report name)
- Date retrieved: when you downloaded it
- Notes: any cleaning or adjustments applied

This ensures reproducibility and makes it easy 
to audit model inputs if outputs are questioned.
