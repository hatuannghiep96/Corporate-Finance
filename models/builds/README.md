# models/builds/

Holds all populated working financial models 
from Stage 3 onwards. Each file here is a 
complete model with real company data.

Version files with descriptive names — do not 
overwrite previous versions.

Naming: YYYY-MM-DD_stage#_description_v#.xlsx
Example: 2026-10-15_stage3_nestle-ratios-v2-final.xlsx
