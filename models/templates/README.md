# models/templates/

This folder contains the base Excel template provided by 
the instructor for BUS-629 Corporate Finance (VEMBA 33).

## Files

| File | Description |
|------|-------------|
| `performance-ratios-template.xlsx` | Instructor-provided ratios template. Do not modify — copy to models/builds/ before populating with data. |

## Template Structure

The workbook contains 6 tabs:
- **Cover & Instructions** — project overview and named-range key
- **Legend** — color-coding guide (yellow = inputs, blue = assumptions, green = formulas, gray = outputs)
- **Income Statement** — skeleton with named-range placeholders (INC_*)
- **Balance Sheet** — current and prior year columns (BAL_*, startYear_*)
- **Cash Flow** — operating, investing, and financing activities (CASH_*)
- **Ratios** — fully formulaic, auto-populates when Stage 3 financials are entered

## Important
Do NOT hardcode numbers into this template.
Always work from a copy in models/builds/.
